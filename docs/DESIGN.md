# HitGO 编辑器界面设计方案（v0.14 视觉改版）

对比稿：https://claude.ai/artifact/HE7MuMWNnWkfRWwMxUdNeX （整屏 + 右侧面板细看，可切主题 / 面板宽 / 竖条用法）
现状基线：v0.13.1，`frontend/src/styles.css` + `components/ui/Section.tsx`。
本文只讲界面形态与令牌，不改契约；涉及契约的点单独标出。

## 1. 要解决的问题

1. 右侧属性面板的分组卡片和面板同色，只靠 1px 软线分隔；标题 12px/500 与标签 12px/400 分不开；折叠态和展开态同形；"属性 · 图层名"这一行比组标题还弱。
2. 界面里有三种"切换"长相：顶栏橙色药丸、面板下划线 tab、橙边 chip。
3. 左栏视频列表海报 34×60，四种信息同一灰度；勾选框与"当前编辑"混在一起，看不出多选；没有重命名 / 移除入口。
4. 顶栏、左栏、右栏、时间线全是同一个面板色，画布区和四周没有前后关系。
5. 三处选中态（左栏当前行、右栏图层行、时间线图层条）各画各的。

## 2. 令牌

### 2.1 三层表面

在现有 `--bg / --panel / --panel-2` 之外新增，浅深各一套，全部定义在 `:root` 与 `html.dark`：

| 令牌 | 作用 | 深色 | 浅色 |
|---|---|---|---|
| `--s0` | 栏底（顶栏、左栏、右栏、时间线） | `#1a1d21` | `#ffffff` |
| `--s1` | 抬起一档：卡片、分段组底、选中行、次级按钮 | `#23272d` | `#f3f4f7` |
| `--s2` | 下沉一档：输入块、滑杆槽、卡片内的分段组 | `#15171b` | `#ffffff`（配 `--s1-line` 边） |
| `--s1-line` | 卡片同级分隔线 | `#2c3037` | `#e6e9ee` |

画布区继续用 `--bg`（最深），前后关系靠亮度而不是边框线。`--panel` 保留给弹窗与列表页，不在编辑器栏里再用。

### 2.2 橙色的语义

`--accent` 只表示状态：当前编辑的对象、激活的模式、唯一的主按钮（导出 / 保存预设）。

- 每屏只有一个实心橙按钮。
- 属性卡片左侧 3px 竖条只在**改过或已启用**的组上出现，与「重置」按钮同时出现、同时消失。
- 品牌字标里的 GO 例外，它是 logo。

### 2.3 字号与间距

| 角色 | 规格 |
|---|---|
| 卡片标题 | 13px / 600 / `--ink` |
| 卡片右侧提示 | 11px / 400 / `--ink-3` |
| 摘要行标题 | 12px / 500 |
| 输入块标签 | 11px / `--ink-3`；数值 12.5px 等宽 `tabular-nums` 右对齐 |
| 卡片 | 圆角 8，内边距 8 10 10，卡片间距 8 |
| 输入块 / 分段组 / 摘要行 | 高 30，圆角 6 |
| 按钮（顶栏） | 高 32，圆角 7 |

## 3. 组件

### 3.1 Section 两态

`components/ui/Section.tsx` 保留全部 props（`id / summary / help / enabled / onToggle / onReset / defaultOpen / bodyClass`）与 `lib/sectionPrefs` 的开合持久化，只换形态：

- **展开 = 卡片**：`--s1` 底，标题 13/600，右侧提示语（`help` 文本直接显示，不再用问号图标），重置按钮 hover 出现，箭头向下。
- **折叠 = 摘要行**：高 30，`--s1` 45% 透明度底，标题 12/500 + 等宽摘要 + 箭头向右。点击整行展开。
- 有 `onToggle` 的组：勾选框换成 26×15 开关；关闭时以摘要行显示，标题灰、摘要写「关」，不可展开。
- 竖条：`enabled === true` 或调用方传入 `changed`（新增可选 prop，默认 `false`）时显示。

### 3.2 输入块（Num 的替代形态）

`标签 | 数值 单位` 一体的 30px 块，`--s2` 底，hover 出边。单击进入编辑；在块上左右拖动按 `step` 微调（scrub）。去掉 72px 固定标签列与两侧 18px 加减钮。颜色块：标签 + 色值 + 14px 色样。下拉块：标签 + 当前值 + 箭头。

### 3.3 分段组

同一容器内多选一：`--s2` 底（在卡片里）或 `--s1` 底（在栏上），内边距 3，激活项 `--s1` / `--panel` 底加 1px 投影，图标变橙。用于：顶栏模块、快捷栏安全区模式、对齐、播放控制、时段全程/区间、播放循环/单次。**橙边 chip 全部退出**，只保留在素材筛选（原料库 / 我上传的）里做多选筛选。

### 3.4 选中态（三处统一）

"当前正在编辑"：`--s1` 底 + 左侧 2px `--accent` 竖条。用于左栏当前视频行、右栏图层行、时间线图层条、音频面板音轨行。
"已勾选（批量目标）"：勾选框 + 行底 `--s1` 60%。两种状态可以叠加。

### 3.5 顶栏按钮

高 32，`--s1` 底 + `--s1-line` 边，图标 `--ink-2`。图标按钮 32×32。撤销 / 重做为连体组。状态文字（已保存）不做成按钮：绿点 + 文字。

## 4. 各区域

### 4.1 顶栏（56px）

- 品牌两行：字标 15/700（GO 橙）在上，版本号等宽 10.5 `--ink-3` 在下，右侧 1px `--s1-line` 竖线。版本号将来若去掉，第二行改显示环境名，保持两行。
- 模块组：图标在上文字在下，每块 52×44，图标 16，文字 11.5。激活项抬起 + 图标橙。六个模块图标：剪辑（剪刀）、音频（波形）、文本（T）、贴纸（折角）、字幕（CC 框）、改语言（地球）。窄于 1280 时可只留图标。
- 右侧：已保存 · [撤销|重做] · 主题 · 产物（带网格图标）· **导出**（唯一实心橙）。

### 4.2 左栏（默认 236px，可拖 210–300）

- 头部：批次名 13/600 + 「4 条」等宽；第二行「全选」+「已选 2 / 4」。
- 视频行：海报 44×78（9:16）· 文件名去扩展名 12.5 · 时长 分辨率 等宽 11 · 状态圆点 + 文字（已编辑 · N 图层 / 未编辑 / 渲染中 / 失败）。
- 勾选框常显，固定在海报左上角，白边深底，勾上变橙带对勾。
- 行操作 hover / 当前行出现在右上角：重命名、从批次移除。
- 底部按钮文案随勾选数变化：「把当前配置应用到已选 N 条」。

### 4.3 中栏

- 快捷栏：对齐三键分段组；安全区 / 遮挡示意 / 关 分段组；平台方案用下拉块；快捷键幽灵图标。
- 播放条：上一帧 / 播放 / 下一帧 分段组；时间等宽，总时长 `--ink-3`。
- 时间线：底 `--s0`；空轨 `--s1` 60%；图层条 `--s1` + 左侧 2px 橙条；「剪掉 / 缩放 / 适应」并入播放条右侧，省回一行 30px 抵消顶栏加高的 12px。

### 4.4 右栏

- 面板内容页仍用下划线 tab（图层 / 原料库 / 我上传的 等）。
- 图层区：「图层 N」小标题 + 添加按钮；行高 26；六个快捷操作（显示 / 锁定 / 上移 / 下移 / 复制 / 删除）原样保留，平时 45% 透明，hover 或选中行全亮；超过三行内部滚动。
- 属性头部：类型图标（`--accent-soft` 底）· 图层名 13/600 · 副标题「贴纸图层 · PNG 1080×640 · N 组改过」· 更多。
- 属性组按 3.1 渲染。文本图层 9 组是压力测试用例。

## 6. 验收

每个 PR 至少看以下场景，深浅两套主题各一遍：

1. 文本图层 9 组全部展开，右栏 260px 最窄。
2. 贴纸图层，右栏 320px 默认，整屏 1280×800 与 1440×900。
3. 左栏勾选 2 条 + 当前编辑另一条，三种状态同时可见。
4. 音频面板（PR 4 起）四类音轨各一条。
5. `make test-frontend` 通过；`lib/` 新增纯函数（scrub 步进）带 vitest。

## 7. 已定的取舍

- 图层列表**不拆**成独立 tab，压缩成紧凑区；图层很多时再议。
- 竖条默认**只在改过 / 已启用的组**上；对比稿里保留「每组都有」开关供比较，默认不采用。
- 模块组采用**图标上文字下**，接受顶栏加高 12px，由时间线头部并行抵消。
- X / Y / 宽度继续用**百分比**，不显示 px。
- 输入块**单击即编辑**，不采用双击。
- 不再新增分类 segmented（基础变换 / 播放时段 / 样式混合），靠展开 / 折叠两态完成分组。

### 8.5 P2 · 待议

## 9. 两处减法的设计说明

### 9.1 撤销 / 重做只留顶栏

**现状。** 顶栏右侧一组，时间线工具条左侧又一组，两组调用同一个 `useEditor().undo / redo`，状态也同步。时间线那组的注释写的是"对齐剪映：与被操作的轨道就近"。快捷键 ⌘Z / ⇧⌘Z 全局有效。

**问题。** 撤销的对象不只是时间线：改属性、动画布上的图层、批量应用、套用语言版本，全部进同一条历史。把按钮放在时间线旁边，会让人以为它只撤销时间线上的操作。两组按钮也让顶栏右侧和时间线左侧各多占 60px。

**提案。**
- 顶栏保留一组，做成 3.5 节的连体组，位置在「已保存」右侧。
- 时间线工具条删掉撤销 / 重做，左侧从「剪掉 / 删左 / 删右 / 删除」开始。
- 撤销按钮 hover 显示将要撤销的动作名，例如「撤销：移动图层」「撤销：批量应用到 2 条」。历史栈现在只存快照，需要给每次 `pushHistorySnapshot` 带一个 `label`，这是 PR 2 里唯一的逻辑改动，不涉及契约。
- 快捷键不变。

**失去什么。** 鼠标在时间线上操作时，撤销要移到右上角。缓解：剪辑相关的撤销大多是键盘 ⌘Z；hover 标签让顶栏那组比原来更有信息量。

**如果不采纳。** 保留两组，但时间线那组改成只对时间线动作可用是做不到的，因为历史是一条栈。所以要么两组都全局，要么一组。

### 9.2 批量应用只留左栏一个入口

**现状。** 两个入口打开的是**同一个** `ApplyDialog`，区别只在默认勾选的模块：
- 左栏底部「批量应用当前配置 → 选中 N 条」：默认勾中全部五个模块（剪辑 / 图层 / 输出 / 音频 / 封面）。
- 右栏底部「把图层 / 音频应用到选中 N 条」：默认只勾中当前模块（文本 / 贴纸 / 字幕 → 图层；音频 → 音频；改语言 → 图层 + 音频）。
两处都在 N = 0 时禁用，但没有说明为什么不能点。右栏那一行在文本、贴纸、字幕、音频、改语言五个模块里都占 48px。

**问题。** 用户看到两个按钮会以为是两种功能。实际是一个弹窗两种预设，预设在弹窗里本来就能改。

**提案。**
- 右栏底部的 `ApplyLayersFoot` 和音频面板底部的同类按钮删掉，五个面板各省 48px。
- 左栏底部保留一个按钮，文案随勾选数变：
  - N = 0：按钮禁用，文案「先在左侧勾选目标视频」。
  - N ≥ 1：「把当前配置应用到已选 N 条」。
- 弹窗打开时默认勾中的模块跟随当前模块（沿用右栏入口现在的规则），弹窗标题写清「从 V01 应用到已选 2 条」，五个模块都在弹窗里可改。这样用户在文本模块点它，得到的默认行为和原来右栏按钮一样。
- 弹窗里的「仅样式（保留目标已有图层文字）」开关保留。

**失去什么。** 在右栏改完属性顺手点底部按钮的路径，变成移到左下角点。距离变长，但两个按钮的困惑消失，右栏多出一行给属性。

**如果不采纳。** 保留右栏按钮但改文案，让它和左栏的关系清楚：左栏写「应用全部配置…」，右栏写「只应用图层…」。这能消除"两种功能"的误解，但右栏的 48px 省不下来。

### 9.3 对 PR 2 的影响

两处都在 PR 2 范围内。改动文件：`TopBar.tsx`、`TimelineTools.tsx`、`VideoList.tsx`（按钮文案）、`EditorPage.tsx`（去掉五个面板的 `onApply / targetCount` 传参）、`LayerParts.tsx`（删 `ApplyLayersFoot`）、`AudioPanel.tsx`（删底部按钮）、`store/editor.ts`（历史快照加 `label`，可选）。`store/editor.ts` 和 `EditorPage.tsx` 是共享文件，PR 描述里要说明。
