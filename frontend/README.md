# HitGO 前端

Vite + React 18 + TypeScript + react-konva + zustand。契约见 `../docs/CONTRACT.md`。

```bash
npm install
npm run dev        # 连本地后端（/api、/media 代理到 8000）
npm run dev:mock   # 纯前端 mock（VITE_MOCK=1），不需要后端 / ffmpeg
npm run typecheck && npm test && npm run build
```

## 编辑器面板

- **顶栏**：功能模块「剪辑 / 音频 / 文本 / 贴纸 / 字幕」（`lib/steps.ts` 的 `STEPS`）、安全区预设、安全区显示三态（框线 / 遮挡示意 / 关闭；所选预设没有示意图时自动退回框线并提示）、撤销 / 重做、保存状态、已回传、**导出**。
- **导出弹窗**：范围单选「这一批全部（默认）/ 左侧勾选的 / 仅当前这条」（`lib/exportScope.ts`），未就绪的视频自动跳过并提示；每条视频按勾选的预设或自定义画幅分别导出文件。
- **快捷操作条（画布下方）**：居中（文本 / 贴纸 / 字幕模块）、安全区显示循环切换、快捷键表。撤销 / 重做、删左 / 删右、删除在时间线工具条。画布随「成片画面」的当前画幅实时预览。
- **左栏 视频列表**：勾选目标后「批量应用当前配置」。对话框按模块显示「将覆盖 N 条已有配置」；图层模块可勾选「只套用样式，不改位置和时段」（`layer_mode: style_only`）。应用后的提示条可「撤销本次批量应用」，每条目标视频自己的 ⌘Z 也能回退。
- **剪辑面板**（HIG-17 做了功能分层）：最上面是常驻的剪辑操作（设入点 / 设出点 / 删左 / 删右 / 删除选中区间），下面是四个可折叠分组 —— **已删除区间**（默认展开）、**封面**（默认折叠）、**成片画面**（默认折叠）、**时长**（默认展开）。分组收起时标题行右侧留一句摘要（`lib/trimSummary.ts`，如「2 段 · −4.00s」「裁切 · 高清 · 约 43 MB」，安全区有图层越界时在摘要里标红），开合状态按分组 id 存本机（`lib/sectionPrefs.ts`，key `hitgo.sections`），刷新后保持。原先常驻面板底部的那段长说明按语义拆进各分组标题旁的「?」气泡（`components/ui/HelpTip.tsx`）；折叠分组组件是 `components/ui/Section.tsx`，与文本 / 贴纸属性里的「位置」「套用样式」共用一套。
  - **封面**（HIG-9，契约 §2 `cover`）：从贴纸库选图片 / 视频（或在选择框里直接上传，支持 jpg）插到成片最前面，图片可调停留时长（默认 1 秒，0.1–10），视频整段播放、保留原声；封面期间不叠图层、不放 BGM，图层与音轨的时间仍从正片算起。时间线最前面画出封面块、正片各行整体右移，播放头可以落进封面段（`time < 0`，见 `lib/cover.ts`），播放时先放封面再无缝接正片，时间码显示成片时间。
  - **成片画面**：可配置 9:16、1:1、4:5、16:9 和一个自定义宽高画幅；自定义输入支持宽高比锁定，宽高需为不小于 2 的偶整数。各画幅可分别设置模糊 / 纯色 / 裁切、裁切范围、标准 / 高清和导出勾选。预览随画幅尺寸变化；过大尺寸提示可能影响性能。大小估算按码率表（`lib/estimate.ts`），打开剪辑面板时拉取本批次已完成任务按实际码率校准。
- **音频面板**（HIG-10，原剪辑面板里的音频分组搬来）：**源音轨** 静音 / 音量；**BGM / 口播** 添加（选素材或直接上传）、时段 / 音量 / 循环 / 起始偏移 / 淡入淡出；**贴纸音轨** 列出带声音的视频贴纸，可开关「合成」（与贴纸面板里的开关是同一个 `mix_audio`）；底部「把音频应用到选中 N 条」打开批量应用并默认只勾音频。时间线上的音轨行（源音轨、BGM / 口播、贴纸音轨）只在音频模块显示；BGM / 口播条可拖动移动、拖两端调整时段（剪后时间轴，吸附 0 / 时长 / 播放头 / 其他音轨与图层端点），轨道头可切换全程 / 区间，Delete 删除选中音轨；贴纸音轨条只读，时段在贴纸模块里改。
- **文本 / 贴纸 / 字幕面板**：文本与贴纸各自只列出、只在画布上选中、只在时间线上显示本类图层；字幕导入后仍是文字图层，沿用文字的画布和时间线交互。层级调整（拖动 / 上下移 / 置顶置底）只在同类之间换序，另一类位置不动（`lib/layerKind.ts`）。批量应用的「图层」模块仍是文字 + 贴纸一起套用。
  - 文本面板 tab（HIG-11 对齐贴纸面板）：**图层**（文字图层列表 + 选中图层的属性）/ **文字**（字体 / 花字 / 气泡三组可折叠卡片平铺：单击只高亮，双击或 Enter 新建一条带该字体 / 样式的文字图层，面板留在本页便于连续添加）/ **模板**（标题模板）。在画布、时间线或列表里选中文字图层时自动切回「图层」页；「文字」页新建的图层不切页。给已有图层换花字 / 气泡在属性里的「套用样式」分组（单击即套用）。卡片数据见 `lib/textGallery.ts`。
  - 字幕面板（HIG-15）：顶栏「贴纸」右侧的独立模块，导入 .srt / .vtt；每条字幕仍生成带时段的文字图层，套用默认字幕条样式并按剪后时长裁剪。
  - 贴纸面板 tab：**图层** / **原料库** / **我上传的**，素材再按「全部 / 图片 / 视频」筛选。
  - 样式预设：11 个内置预设（白字黑边 / 黄字黑边标题 / 黑底白字字幕条 / 红底白字促销 / 空心描边 / 投影浮起 / 发光标题 / 半透明气泡 / 黄底通栏标题 / 黄底圆角标题 / 深底青字副标题；带背景的归「气泡」，其余归「花字」）+ 用户预设（`/api/presets`，悬停显示 ✕ 删除）；「存为预设」保存选中文字图层的全部样式。预设不含对齐，字号只在预设自带时才覆盖。
  - 文字样式新增：阴影（颜色 / 模糊 / 偏移 X、Y，均相对画布高）、字距（em，可为负）、内边距、行高。预览与成片 PNG 都由 `lib/textImage.ts` 同一函数绘制。
- **多画幅**：9:16 始终作为图层设计的参考画布；其它画幅的图层默认跟随视频画面，并可单独微调。自定义画幅随视频配置保存，可与预设画幅一起导出，见契约 §2。

## 快捷键

清单在 `src/lib/shortcuts.ts`（按钮提示和 `?` 速查表共用同一份）。「剪辑」组只在剪辑模块生效，「音频」组只在音频模块生效，「图层」组在文本、贴纸、字幕模块里生效（字幕沿用文字图层，因此支持文字样式与画布编辑）。mac 显示 ⌘ / ⌥ / ⇧，Windows 显示 Ctrl / Alt / Shift。

| 分组 | 键位 | 作用 |
| --- | --- | --- |
| 全局 | 空格 | 播放 / 暂停 |
| 全局 | ← / → | 上一帧 / 下一帧 |
| 全局 | ⇧← / ⇧→ | 后退 / 前进 1 秒 |
| 全局 | ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| 全局 | ⌘S | 保存 |
| 全局 | ? | 快捷键列表 |
| 全局 | Esc | 取消选择 / 关闭弹窗 |
| 剪辑 | I / O | 设入点 / 出点 |
| 剪辑 | Q / W | 删左 / 删右 |
| 剪辑 | Delete | 删除选中区间 |
| 音频 | 拖动 | 拖动音轨条移动时段 / 拖两端调整 |
| 音频 | Delete | 删除选中音轨 |
| 图层 | ⌘C / ⌘V | 复制 / 粘贴图层 |

## 目录

- `src/api.ts` 类型化 API 客户端；`src/mocks/index.ts` 内存 mock（预设会存到 `localStorage["hitgo.mock.presets"]`，示意图为生成的 data URL）。
- `src/store/editor.ts` 编辑器状态（草稿 spec、历史、自动保存、批量应用、预设、渲染轮询）。
- `src/lib/` 纯函数：`spec`、`time`、`layout`、`snap`、`estimate`、`textImage`、`textPresets`、`shortcuts`、`steps`、`layerKind`、`exportScope`（带 vitest）。
