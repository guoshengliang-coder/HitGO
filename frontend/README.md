# HitGO 前端

Vite + React 18 + TypeScript + react-konva + zustand。契约见 `../docs/CONTRACT.md`。

```bash
npm install
npm run dev        # 连本地后端（/api、/media 代理到 8000）
npm run dev:mock   # 纯前端 mock（VITE_MOCK=1），不需要后端 / ffmpeg
npm run typecheck && npm test && npm run build
```

## 编辑器面板

- **顶栏**：步骤切换（① 剪辑 / ② 图层 / ③ 输出）、安全区预设、安全区显示三态（框线 / 遮挡示意 / 关闭；所选预设没有示意图时自动退回框线并提示）、撤销 / 重做、保存状态、保存并回传。
- **快捷操作条（画布下方）**：撤销 / 重做、删左 / 删右、删除、居中、安全区显示循环切换、输出比例、快捷键表。
- **左栏 视频列表**：勾选目标后「批量应用当前配置」。对话框按模块显示「将覆盖 N 条已有配置」；图层模块可勾选「只套用样式，不改位置和时段」（`layer_mode: style_only`）。应用后的提示条可「撤销本次批量应用」，每条目标视频自己的 ⌘Z 也能回退。
- **② 图层面板**：
  - 文字图层顶部是**样式预设条**：7 个内置预设（白字黑边 / 黄字黑边标题 / 黑底白字字幕条 / 红底白字促销 / 空心描边 / 投影浮起 / 半透明气泡）+ 用户预设（`/api/presets`，悬停显示 ✕ 删除）；「存为预设」在面板内输入名称保存当前图层的全部样式。预设不含对齐，字号只在预设自带时才覆盖。
  - 文字样式新增：阴影（颜色 / 模糊 / 偏移 X、Y，均相对画布高）、字距（em，可为负）、内边距、行高。预览与成片 PNG 都由 `lib/textImage.ts` 同一函数绘制。
- **③ 输出面板**：每个变体可选质量 **标准 / 高清**（`outputs[].quality`，对应 worker 的两档 x264 参数），并显示「约 12 MB（估算）」；规格摘要显示编码档位与总大小。估算按码率表（`lib/estimate.ts`），进入步骤 3 时会拉取本批次已完成任务按实际码率校准。

## 目录

- `src/api.ts` 类型化 API 客户端；`src/mocks/index.ts` 内存 mock（预设会存到 `localStorage["hitgo.mock.presets"]`，示意图为生成的 data URL）。
- `src/store/editor.ts` 编辑器状态（草稿 spec、历史、自动保存、批量应用、预设、渲染轮询）。
- `src/lib/` 纯函数：`spec`、`time`、`layout`、`snap`、`estimate`、`textImage`、`textPresets`、`shortcuts`（带 vitest）。
