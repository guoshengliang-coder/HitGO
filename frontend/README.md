# HitGO 前端

Vite + React 18 + TypeScript + react-konva + zustand。契约见 `../docs/CONTRACT.md`。

```bash
npm install
npm run dev        # 连本地后端（/api、/media 代理到 8000）
npm run dev:mock   # 纯前端 mock（VITE_MOCK=1），不需要后端 / ffmpeg
npm run typecheck && npm test && npm run build
```

## 编辑器面板

- **顶栏**：功能模块「剪辑 / 音频 / 文本 / 贴纸」（`lib/steps.ts` 的 `STEPS`，新增模块只需追加一项，没有先后顺序）、安全区预设、安全区显示三态（框线 / 遮挡示意 / 关闭；所选预设没有示意图时自动退回框线并提示）、撤销 / 重做、保存状态、已回传、**导出**。
- **导出弹窗**：范围单选「这一批全部（默认）/ 左侧勾选的 / 仅当前这条」（`lib/exportScope.ts`），未就绪的视频自动跳过并提示；每条视频出一个 9:16 文件。
- **快捷操作条（画布下方）**：居中（文本 / 贴纸模块）、安全区显示循环切换、快捷键表。撤销 / 重做、删左 / 删右、删除在时间线工具条。画布固定 9:16。
- **左栏 视频列表**：勾选目标后「批量应用当前配置」。对话框按模块显示「将覆盖 N 条已有配置」；图层模块可勾选「只套用样式，不改位置和时段」（`layer_mode: style_only`）。应用后的提示条可「撤销本次批量应用」，每条目标视频自己的 ⌘Z 也能回退。
- **剪辑面板**：删除区间；**画面**（原「输出」步骤搬来）：填充方式 模糊 / 纯色 / 裁切（源已是 9:16 时不显示）、裁切范围（中栏换成裁切编辑器）、清晰度 **标准 / 高清**（`outputs[].quality`，对应 worker 的两档 x264 参数）与「约 12 MB（估算）」、安全区重叠检查。估算按码率表（`lib/estimate.ts`），打开剪辑面板时拉取本批次已完成任务按实际码率校准。
- **音频面板**（HIG-10，原剪辑面板里的音频分组搬来）：**源音轨** 静音 / 音量；**BGM / 口播** 添加（选素材或直接上传）、时段 / 音量 / 循环 / 起始偏移 / 淡入淡出；**贴纸音轨** 列出带声音的视频贴纸，可开关「合成」（与贴纸面板里的开关是同一个 `mix_audio`）；底部「把音频应用到选中 N 条」打开批量应用并默认只勾音频。时间线上的音轨行（源音轨、BGM / 口播、贴纸音轨）只在音频模块显示；BGM / 口播条可拖动移动、拖两端调整时段（剪后时间轴，吸附 0 / 时长 / 播放头 / 其他音轨与图层端点），轨道头可切换全程 / 区间，Delete 删除选中音轨；贴纸音轨条只读，时段在贴纸模块里改。
- **文本 / 贴纸面板**：两个模块各自只列出、只在画布上选中、只在时间线上显示本类图层；层级调整（拖动 / 上下移 / 置顶置底）只在同类之间换序，另一类位置不动（`lib/layerKind.ts`）。批量应用的「图层」模块仍是文字 + 贴纸一起套用。
  - 文本面板 tab：**文字**（列表 + 属性）/ **花字** / **气泡**（预设墙：有选中文字时套用，没有时新建一条该样式的文字）/ **模板**（标题模板）/ **字幕**（导入 .srt）。
  - 贴纸面板 tab：**图层** / **原料库** / **我上传的**，素材再按「全部 / 图片 / 视频」筛选。
  - 样式预设：7 个内置预设（白字黑边 / 黄字黑边标题 / 黑底白字字幕条 / 红底白字促销 / 空心描边 / 投影浮起 / 半透明气泡）+ 用户预设（`/api/presets`，悬停显示 ✕ 删除）；「存为预设」保存选中文字图层的全部样式。预设不含对齐，字号只在预设自带时才覆盖。
  - 文字样式新增：阴影（颜色 / 模糊 / 偏移 X、Y，均相对画布高）、字距（em，可为负）、内边距、行高。预览与成片 PNG 都由 `lib/textImage.ts` 同一函数绘制。
- **多画幅已下线**（HIG-8）：编辑器只产出一个 9:16 输出，旧 spec 里的 1:1 / 4:5 / 16:9 变体和 `layer_overrides` 在载入时被收掉并写回（`lib/spec.ts` 的 `toSingleOutput`），见契约 §2。

## 快捷键

清单在 `src/lib/shortcuts.ts`（按钮提示和 `?` 速查表共用同一份）。「剪辑」组只在剪辑模块生效，「音频」组只在音频模块生效，「图层」组在文本、贴纸两个模块里生效（复制 / 粘贴文字样式、画布编辑文字只在文本模块）。mac 显示 ⌘ / ⌥ / ⇧，Windows 显示 Ctrl / Alt / Shift。

| 分组 | 键位 | 作用 |
| --- | --- | --- |
| 全局 | 空格 | 播放 / 暂停 |
| 全局 | ← / → | 上一帧 / 下一帧 |
| 全局 | ⇧← / ⇧→ | 后退 / 前进 1 秒 |
| 全局 | ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| 全局 | ⌘S | 保存 |
| 全局 | ? | 快捷键列表 |
| 全局 | Esc | 取消选择 / 关闭弹窗 |
| 剪辑 | I / O | 设入点 / 出点 |
| 剪辑 | Q / W | 删左 / 删右 |
| 剪辑 | Delete | 删除选中区间 |
| 音频 | 拖动 | 拖动音轨条移动时段 / 拖两端调整 |
| 音频 | Delete | 删除选中音轨 |
| 图层 | ⌘C / ⌘V | 复制 / 粘贴图层 |
| 图层 | ⌘D | 创建副本 |
| 图层 | ⌥⌘C / ⌥⌘V | 复制 / 粘贴文字样式 |
| 图层 | ] / [ | 上移 / 下移一层 |
| 图层 | ⇧] / ⇧[ | 置顶 / 置底 |
| 图层 | ↑↓←→ | 微移 1 px（参考 1080×1920） |
| 图层 | ⇧↑↓←→ | 微移 10 px |
| 图层 | ⌥←→ | 选中图层时仍逐帧 |
| 图层 | Delete | 删除图层 |
| 时间轴 | ⌘ + 滚轮 | 缩放时间轴 |
| 时间轴 | 滚轮 | 横向滚动 |
| 时间轴 | ⇧Z | 适应窗口 |
| 时间轴 | ⌥ + 拖动 | 拖动时不吸附 |
| 画布 | ⌘ + 拖动 | 画布拖动时不吸附 |

## 目录

- `src/api.ts` 类型化 API 客户端；`src/mocks/index.ts` 内存 mock（预设会存到 `localStorage["hitgo.mock.presets"]`，示意图为生成的 data URL）。
- `src/store/editor.ts` 编辑器状态（草稿 spec、历史、自动保存、批量应用、预设、渲染轮询）。
- `src/lib/` 纯函数：`spec`、`time`、`layout`、`snap`、`estimate`、`textImage`、`textPresets`、`shortcuts`、`steps`、`layerKind`、`exportScope`（带 vitest）。
